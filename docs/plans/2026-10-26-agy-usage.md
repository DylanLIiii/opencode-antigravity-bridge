# Antigravity Usage Implementation Plan

**Goal:** Display actual agy subscription quotas in Magpie without owning Google credentials.

**Architecture:** A dependency-free `usage.mjs` parses structured reports and runs
bounded, isolated agy probes. `index.mjs` exposes it through `auth.usage`; inference
and its existing cumulative-token translation remain untouched.

**Tech Stack:** Node/Bun ES modules, `node:child_process`, `node:test`, Magpie usage hook.

## Task 1: Report parsing
- Create `test-usage.mjs` with synthetic reports for camel/snake case fields,
  nested fractions, multiple and model-specific groups, weekly-only quotas,
  zero/full/unknown/disabled fractions, explicit cadence, and reset validation.
- Run `node --test test-usage.mjs`; expect missing module/export failure first.
- Create `usage.mjs`: `parseUsageReport` returns Magpie windows with percent used,
  seconds per explicit cadence, resets, and display-only semantics; errors are sanitized.
- Rerun focused tests.

## Task 2: Isolated CLI execution
- Extend `test-usage.mjs` with a fake agy executable and recording environment.
- Test version gating, exact `/usage` arguments, restricted agent, browser guards,
  update suppression, output/time budgets, nonzero exits, cancellation, cleanup,
  concurrent deduplication, fresh sequential reads, and launch failures.
- Implement `createUsageReader` in `usage.mjs`; share only in-flight work.
- Rerun focused tests under Node and Magpie's Bun.

## Task 3: Host integration and packaging
- Modify `index.mjs` to add `auth.usage` using the existing `findAgy` resolver.
- Add `usage.mjs` to `package.json`'s publication files and test scripts.
- Extend `test-smoke.mjs`'s fake agy and assertions to exercise the public hook.
- Update `README.md` and `HANDOFF.md` with behavior, platform/version constraints,
  refresh commands, and measured verification (do not claim unrun live tests).
- Run syntax checks, `node --test test-usage.mjs`, `node test-smoke.mjs`, Bun
  equivalents, `npm pack --dry-run`, and `git diff --check`.
- If available and authorized, verify a real report/isolated host without changing
  the user's global installation. Do not push or publish without authorization.
